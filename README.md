🏙️ FIAS Детектор
Графическое приложение на Java (Swing) для поиска и валидации российских адресов через сервис DaData - официальный провайдер подсказок по ФИАС (Федеральная информационная адресная система).

Программа по введённому адресу возвращает полный нормализованный адрес, FIAS ID и географические координаты.

✨ Возможности
🔍 Поиск адреса по подсказкам DaData

🆔 Получение FIAS ID (уникальный идентификатор объекта в ГАР/ФИАС)

📍 Координаты (широта / долгота)

✅ Валидация и нормализация адреса

🖥️ Простой графический интерфейс на Swing

🌐 Работает на Linux, Windows, macOS

🛠 Требования
Компонент	Версия
Java (JDK)	11 или выше
Интернет	обязателен (доступ к suggestions.dadata.ru)
API-ключ DaData	обязателен, см. ниже
🔑 Получение API-ключа DaData
Зарегистрируйтесь на dadata.ru.

В личном кабинете откройте раздел API-ключи.

Скопируйте API-ключ (он понадобится ниже).

Бесплатный тариф: ~10 000 запросов в сутки.

```
⚠️ Не публикуйте ключ в открытых репозиториях. Храните его в переменной окружения.
```

🚀 Установка и запуск
1. Установите JDK
```bash
# Ubuntu / Debian / Mint
sudo apt install default-jdk
```
```bash
# Fedora
sudo dnf install java-17-openjdk-devel
```
```bash
# Arch
sudo pacman -S jdk-openjdk
```
Проверка:

```bash
java -version   # должно быть 11+
```
2. Скачайте и скомпилируйте
```bash
git clone https://github.com/ваш-логин/fias-detector.git
cd fias-detector
javac AddressValidator.java
```
3. Передайте токен
Рекомендуемый способ - переменная окружения:

```bash
export DADATA_TOKEN="ваш_ключ_из_личного_кабинета"
```
В коде это читается так:

```java
private static final String TOKEN = System.getenv("DADATA_TOKEN");
private static final String API_URL =
    "https://suggestions.dadata.ru/suggestions/api/4_1/rs/suggest/address";
```
Альтернатива (менее безопасно): вписать ключ прямо в константу TOKEN.

4. Запустите
```bash
java AddressValidator
```
💻 Использование
🏠 Введите адрес в верхнее поле (например: Москва, Красная площадь, 1).

🔎 Нажмите «Найти адрес» или клавишу Enter.

📋 В нижней панели появятся:

полный нормализованный адрес;

FIAS ID;

координаты (широта, долгота).

🧹 «Очистить» — сбросить поля.

ℹ️ «О программе» — версия и сведения.

🔧 Особенности реализации
Нормализация адреса — удаляются служебные части («корпус», «квартира»), формат приводится к виду, который лучше понимает DaData.

Асинхронный запрос через SwingWorker — интерфейс не «замерзает».

Обработка ошибок: сетевые сбои, неверный токен, пустой ответ API.

Иконка и стиль рисуются программно — без внешних ресурсов.

⚠️ Известные ограничения
Показывается только первая подсказка из ответа.

JSON парсится вручную (без библиотеки), поэтому сложные поля могут теряться.

Нет поддержки прокси.

Планы: переход на Gson, вывод списка вариантов, тёмная тема.
